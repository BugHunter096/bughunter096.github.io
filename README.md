# Portfolio de Pelayo Alonso

Portfolio estático en HTML/CSS/JS. No necesita frameworks.

## Publicarlo en GitHub Pages

1. Crea un repositorio llamado `bughunter096.github.io`.
2. Copia dentro estos archivos:
   - `index.html`
   - `styles.css`
   - `script.js`
3. Haz commit y push a `main`.
4. Entra en Settings → Pages.
5. Source: Deploy from a branch.
6. Branch: `main`, folder `/root`.

Tu web quedará en:

```txt
https://bughunter096.github.io
```

## Cambios rápidos antes de subir

- Sustituye `TU_LINKEDIN_AQUI` por tu LinkedIn.
- Añade capturas reales de proyectos cuando las tengas.
- Actualiza los enlaces de los repos nuevos después de crearlos.
