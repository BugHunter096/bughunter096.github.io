Java · JavaFX · SQLite Proyecto DAM

Progresión de marcas en natación

Aplicación de escritorio para clubes de natación: gestión de nadadores, registro de marcas, filtros y visualización de evolución deportiva.

  • CRUD completo de nadadores y registros.
  • Base de datos SQLite local.
  • Separación entre vista, controladores, DAO y modelos.

Posibles mejoras:

  • Migración de almacenamiento local SQLite a Firebase para permitir acceso multiplataforma y sincronización de datos en tiempo real.
  • Añadir roles. Admin del club, entrenador y nadador/padre.
  • Exportar informes en PDF donde ponga la mejora en los ultimos meses, la mejor marca, la última competición y las observaciones del entrenador.
